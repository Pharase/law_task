    การเชื่อมต่อ LINE OA · Linkage

    กำลังโหลด…

    เปลี่ยน OA ใหม่: ใส่ token + secret ของ OA ใหม่ แล้วนำ Webhook URL ด้านล่างไปใส่ใน Messaging API → Webhook settings (เปิด Use webhook) · ถ้า LIFF ID ใหม่ใช้ไม่ได้ แอปจะกลับไปใช้ LIFF เดิมเอง · OA ต่าง provider = LINE ID ของทุกคนเปลี่ยน ต้องลงทะเบียนใหม่

    การเชื่อมต่อ Google Sheet · Linkage

    กำลังโหลด…

    ระบบทดสอบอ่านชีตด้วยค่าใหม่ก่อน ถ้าไม่ผ่านจะไม่บันทึก (ค่าเดิมยังใช้ได้ต่อ) · ใช้เมื่อย้ายไปสคริปต์ / ชีตใหม่ หรือเปลี่ยน API_SECRET

    วิธีอัปเดตค่าใน Supabase secret

    ค่าที่บันทึกในแอป (2 หัวข้อด้านบน) ใช้ก่อนเสมอ · Supabase secret เป็นค่าสำรอง ใช้เมื่อไม่ได้บันทึกค่าในแอป หรือเมื่อลบค่าในแอปออก

    1. เปิด Supabase → Edge Functions → Secrets (ล็อกอินด้วยบัญชีเจ้าของโปรเจกต์)
    2. กดแก้ไขชื่อที่ต้องการ ใส่ค่าใหม่ แล้วกด Save:
      • LINE_MESSAGING_TOKEN · Channel access token ของ LINE OA
      • LINE_CHANNEL_SECRET · Channel secret ของ LINE OA
      • GSHEET_URL · Web app URL ของ Apps Script (…/exec)
      • GSHEET_SECRET · ค่าเดียวกับ Script property API_SECRET
    3. ค่าใหม่มีผลภายในไม่กี่นาที ไม่ต้อง deploy ใหม่ · ถ้าในแอปมีค่าบันทึกไว้ ค่าในแอปยังใช้ก่อน
    4. ตรวจด้วยปุ่ม "ตรวจลิงก์ Google Sheet และ Drive" และ "ทดสอบส่ง LINE ถึงฉัน"

    LINE_CHANNEL_ID ตั้งโดย GitHub Actions ทุกครั้งที่ deploy (แก้ในไฟล์ .github/workflows/supabase-deploy.yml) · SUPABASE_URL และ SUPABASE_SERVICE_ROLE_KEY Supabase ตั้งให้เอง ไม่ต้องแก้
